# Feuille de route des nouvelles API

Les API ci-dessous sont en cours de conception ou de construction. Les dates sont indicatives et peuvent évoluer. Pour être associé à une phase bêta, contactez l'équipe productrice indiquée ou écrivez à l'équipe du catalogue.

<!-- feuille-de-route -->

La feuille de route est générée à partir du fichier `data/feuille_de_route.yml`. Chaque jalon marqué `mise_en_production: true` fusionne la branche de l'API dans le catalogue.
